# Inled Pulsar OS F-Droid Repository

Repositorio oficial de aplicaciones Android para [Pulsar OS](https://github.com/Inled-Pulsar-OS) e [InledGroup](https://github.com/InledGroup).

## Cómo añadir el repositorio

### 1. Enlace directo en Android
Si estás en tu teléfono Android con F-Droid, Droid-ify o Neo Store instalado:
- [Añadir a F-Droid](fdroidrepos://fdroid.inled.es/repo)

### 2. URL del Repositorio
```text
https://fdroid.inled.es/repo
```
